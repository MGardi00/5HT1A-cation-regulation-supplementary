# 5HT1A-cation-regulation-supplementary
Official data repository for "Cation-Mediated Regulation of the Conformational Landscape Underlying Constitutive Activity in the Human 5-HT1A Receptor" (Gardi, Massaccesi, Galeazzi). Contains GROMACS input files (.tpr) for all systems and replicas, alongside representative structures (.gro) and interaction energy profiles for key systems.
